실시간 동기화 (Firebase)

여러 기기·선생님이 같은 데이터를 실시간으로 공유합니다. Firebase 프로젝트를 만든 뒤 설정(config)을 붙여넣고 연결하세요. 오프라인이면 이 기기의 로컬 저장으로 동작합니다.

상태:오프라인
▸ 설정 방법 (5분)
  1. console.firebase.google.com 에서 프로젝트 생성(무료)
  2. 좌측 빌드 → Realtime Database → 데이터베이스 만들기 → 위치 선택 → 테스트 모드로 시작
  3. 프로젝트 개요 옆 ⚙ 설정 → 프로젝트 설정 → 하단 ‘앱’에서 웹(</>) 추가 → 앱 등록
  4. 표시되는 firebaseConfig 객체를 복사해 위 칸에 붙여넣고 연결
  5. 다른 기기에서도 같은 config로 연결하면 실시간 공유됩니다
